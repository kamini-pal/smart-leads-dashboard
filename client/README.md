# Smart Leads — Frontend

React + TypeScript + Vite client for the Smart Leads Dashboard.

See the **[main README](../README.md)** for full setup, Docker instructions, and API documentation.

## Quick start (local)

```bash
cp .env.example .env
npm install
npm run dev
```

App runs at `http://localhost:5173` (API proxied to `http://localhost:5000`).
